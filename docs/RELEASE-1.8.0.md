# 2b2m 1.8.0

Adds Oritech 1.2.13, Applied Energistics 2 19.2.18, and Powah! Rearchitected
6.2.10 for Minecraft 1.21.1 / NeoForge 21.1.265. Athena 4.0.6 and GuideME
21.1.22 are added as required dependencies; existing Architectury, GeckoLib
and Cloth Config satisfy the remaining dependencies. All existing mod files
and gameplay settings are preserved. Clients must update the complete pack.

Powah! Rearchitected is Technici4n's maintained continuation. Its 1.21.1
6.2.10 release was published April 29, 2026 with a block-state fix:
https://github.com/Technici4n/Powah/releases/tag/v6.2.10

The client pack contains 149 JARs and the server candidate contains 154.
CurseForge, Modrinth and Prism/Packwiz exports pass archive/hash checks. The
complete pack passed fresh-world startup and a physical copy of the stopped
production world, with three consecutive 20 TPS samples after startup. The
website's 81 tests and build pass. Native Windows acceptance is in progress.
Production deployment waits for the separate host security-maintenance owner.

Adding AE2 makes the already documented Advanced Peripherals 0.8.2a ME Bridge
and blank ME disk performance concerns applicable. AP remains unchanged; no
bridge/disk restriction or security patch is part of this release.
